# Helpdesk Ticketing Mini-Lab

A compact, role-targeted helpdesk workflow simulation for first-line IT support roles. It models 10 realistic tickets using a Zendesk/Freshdesk-style lifecycle without claiming production use of either platform.

## Evidence status

- **Professional experience:** not claimed by this mini-lab.
- **Zendesk/Freshdesk:** workflow familiarity only; no production administration is claimed.
- **Ticket lifecycle:** simulated with realistic priority, status, SLA, troubleshooting, escalation, user communication and closure notes.
- **Validation:** ticket records are checked by an executable Python script in GitHub Actions.

## What this demonstrates

- first-line triage and troubleshooting
- ticket logging, priority and status management
- SLA awareness
- Active Directory-style account/password/access scenarios
- hardware, software and connectivity troubleshooting
- phishing/security escalation
- L1-to-L2 escalation judgement
- user-facing communication
- closure notes and knowledge capture
