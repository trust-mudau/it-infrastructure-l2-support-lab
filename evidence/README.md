# Evidence Policy

Evidence in this repository must be truthful, sanitized and reproducible.

## Accepted evidence

- GitHub Actions logs from workflows in this repository
- workflow artifacts containing generated logs/checksums
- sanitized command output
- screenshots captured after real execution
- configuration files used in the scenario
- ticket and incident notes tied to actual scenario output

## Not accepted

- invented screenshots
- fabricated command results
- claims of production administration based on lab work
- credentials, tokens, private keys or personal secrets
- copied evidence from unrelated systems

## Status labels

**Executed:** command/workflow actually ran.  
**Scenario validated:** realistic simulated incident was investigated and resolved using generated or supplied evidence.  
**Designed only:** scenario/documentation exists but was not executed.  
**Not implemented:** excluded because of environment/licensing/hardware limitations.
